# App Model

A simple Hello World React Native app built with Expo.

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm start
   ```

3. Follow the Expo CLI instructions to run the app on your device, simulator, or web browser.

## Usage

The app displays "Hello World!" centered on the screen.

## Requirements

- Node.js
- Expo CLI (installed globally or via npx)
- For mobile: Expo Go app on your device or a simulator/emulator set up.
